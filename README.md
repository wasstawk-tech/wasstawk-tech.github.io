# Wassim Tawk — Portfolio

Personal portfolio site for **Wassim Tawk**, Full Stack Developer & AI Automation Engineer based in Lebanon.

Plain HTML, CSS and JavaScript — no build step. Hosted with GitHub Pages.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | All page content (about, experience, projects, skills, education, contact) |
| `style.css` | Styling, dark/light themes, responsive layout |
| `script.js` | Theme toggle, mobile menu, copy-email button, scroll animations |

## Publish on GitHub Pages

1. Create a new **public** repository on GitHub. Name it `<your-username>.github.io` to get the site at `https://<your-username>.github.io`
   (any other name works too, the site will live at `https://<your-username>.github.io/<repo-name>`).
2. Upload `index.html`, `style.css`, `script.js` and this `README.md` to the repository (**Add file → Upload files**), then commit.
3. Go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
4. Wait a minute or two, then open the URL shown on the Pages settings screen.

## Editing

All text lives in `index.html`, one `<section>` per part of the page. To add a project, copy one `<article class="project">` block and change its text.
